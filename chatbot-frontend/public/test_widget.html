🎓 Universitas Contoh

Website simulasi untuk menguji widget chatbot RAGChat. Klik tombol chat di pojok kanan bawah!

Selamat Datang

Ini adalah halaman simulasi website client. Tujuannya untuk menguji apakah file widget.js berhasil menyuntikkan tombol chatbot dan membuka jendela chat iframe.

📋 Cara Penggunaan

Ganti nilai RAGCHAT_API_KEY di bawah dengan API Key instansi yang ingin diuji, lalu refresh halaman ini.

🔗 Integrasi

Untuk mengintegrasikan chatbot ke website Anda, cukup tambahkan kode berikut sebelum tag </body>:

<script>
  window.RAGCHAT_API_KEY = "API_KEY_ANDA";
  window.RAGCHAT_BASE_URL = "http://localhost:3000";
</script>
<script src="http://localhost:3000/widget.js"></script>
