Simulasi Website Eksternal Klien

Portal Layanan Informasi Mahasiswa

Ini adalah contoh website milik klien (pihak ketiga) yang memasang widget chatbot dari provider Anda.

🌐 Bagaimana Website Ini Terhubung ke RAG Kita?

Website ini sama sekali tidak memiliki backend AI, tidak memiliki database vektor, dan tidak memiliki kodingan chat. Website ini hanya menempelkan 4 baris script embed dari server provider Anda.

👉 Lihat di pojok kanan bawah layar: Ada tombol bulat berwarna ungu 💬 yang muncul secara otomatis karena script di bawah ini!
<!-- KODE EMBED CHATBOT DARI SERVER PROVIDER -->
<script>
  window.RAGCHAT_API_KEY = "rc_live_universitas_indonesia_1740642f4457"; // <-- API Key Instansi Klien
  window.RAGCHAT_BASE_URL = "http://localhost:3000";
</script>
<script src="http://localhost:3000/widget.js"></script>

💡 Coba Sekarang

  1. Klik tombol 💬 di pojok kanan bawah.
  2. Isi form nama/email (atau langsung kirim pertanyaan).
  3. Tanyakan sesuatu sesuai dokumen PDF yang sudah di-upload untuk instansi ini.
  4. Jawaban akan dirangkum oleh model AI lokal berdasarkan database vektor milik instansi tersebut!
